# UI 拍板紀錄（docs/ui/decision-log.md）

## v1（2026-09-15，G3.5）

- **選定：C 學習導向**（`docs/ui/v1-C.html`）。
  - iPad 橫向：左側方塊區＋底部操作列；右側學習面板，分「操作」「示範」兩個分頁。
  - 手機直向：方塊在上，學習面板改為方塊下方可拉起的抽屜。
- 製作人附帶要求：一般玩家不懂外層／中層與 U D L R F B 的意思 → 需在教學中說明（規格附錄 C 修訂 R-2）。
- 同時拍板：「最短示範」改名「建議解示範」；拖曳視角放開後吸附正朝向；撤銷扣回步數；教學目標是讓零基礎的人學會層先法，不追求速解。

### 給 game-engineer 的實作備註（ui-designer 稿的已知差異，以規格為準）
1. 靜態稿寫「最短示範」「第 1／7 段」→ 依規格改為「建議解示範」與規格 §8 的分段數。
2. 靜態稿以 `hidden` 屬性控制顯示時，須補 `[hidden]{display:none!important}`（見 ui-designer 回報）。
3. 抽屜使用一般文件流，展開時壓縮方塊區高度，避免方塊被蓋住。
4. 同頁不得出現重複 `id`。
