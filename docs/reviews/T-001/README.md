# T-001 G4.5 外部 AI 審查：操作說明（給製作人）

1. 程式約 380 KB，分成 4 個檔：`review-pack-1.md`～`review-pack-4.md`（每個檔都能單獨閱讀）。
2. 建議做法：在 ChatGPT 或 Gemini 開一個新對話，**把 4 個檔一次上傳**，並輸入「請依檔案第 0 節的規則審查，四批都看完後，用第 6 節的表格一次回覆」。若平台不能上傳檔案，就分 4 次貼上內容，最後一批貼完再請它回覆。
3. 把 AI 的回覆**原文**整段貼回給幕僚長（註明是哪個 AI）；幕僚長會存成 `external-<AI名>.md`，再做裁決表 `triage.md`，原則是「有共識再改」。

| 檔案 | 內容 | 大小 |
|---|---|---|
| `review-pack-1.md` | engine（狀態機、方塊模型、打亂）與資料檔，10 個檔 | 70,797 bytes |
| `review-pack-2.md` | 求解器（兩階段法、層先法、Worker），3 個檔 | 84,855 bytes |
| `review-pack-3.md` | UI 骨架（主程式、記號鍵、手勢、CSS 3D、求解器用戶端），8 個檔 | 122,956 bytes |
| `review-pack-4.md` | UI 學習功能（示範、提示、教學、完成畫面）與打包腳本，7 個檔 | 102,307 bytes |

產生方式：`python3 scratch/s10/gen.py`（程式碼由腳本逐行帶行號輸出，行數已與 `wc -l` 逐檔核對一致）。
