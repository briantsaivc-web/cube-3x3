### 新增
- 遊戲定位：讓手邊沒有實體方塊的人可以玩，也可以看電腦怎麼解（學習用）。
- 自由練習：打亂（隨機合法轉動，畫面標示「非 WCA 官方打亂」）、手勢轉層與轉視角、36 顆記號鍵（外層 18、整顆轉 9、中層 9，附中文副標，中層預設收合）、撤銷／重做（撤銷扣回步數）、重設、計時、QTM 步數（外層 90°＝1、180°＝2；中層 90°＝2、180°＝4；整顆轉＝0）。
- 提示：顯示下一步記號、白話說明與要轉的層；用過提示的局在完成畫面標「有提示」。
- 看電腦解：「建議解示範」（自寫兩階段求解器，以 QTM 成本搜尋；1,000 個隨機狀態平均 27.63 步、最長 32 步）與「層先法示範」（8 段、11 個初學者公式，每段結束暫停並說明下一段）；播放、暫停、單步、速度。看過示範的局不列紀錄。
- 首次教學與「記號小教室」（7 步，每步在方塊上實際示範並高亮該層）；可略過，可從「記號說明」重看；面標籤開關。
- 完成畫面與本機最佳紀錄（儲存不可用時不顯示，遊戲照常可玩）。
- 版面：G3.5 選定的 C 版（iPad 橫向右側學習面板；手機直向方塊下方抽屜）。
- 架構：engine 純函數 reducer＋seeded RNG；求解器於 Web Worker 執行（Blob 由同一檔案產生），建立失敗時退回主執行緒；以搜尋節點上限控制搜尋，結果可重現。
- build：單一 `index.html`，381,059 bytes（主產物上限 400 KB，D-13），Worker 字串 84,029 bytes，零外部資源，決定性輸出。
- 測試：engine／求解器／資料 Node 測試 100 項；Playwright UI 測試 35 項 × 手機直向 390×844、iPad 橫向 1194×834。
